# Крышка

Переключатель: Mac засыпает при закрытой крышке или нет. Если сон выключен, он включается сам через выбранное время — от 1 минуты до 24 часов.

Страница открывается на этом Mac: <http://127.0.0.1:8737>

## Почему это не Docker

Docker Desktop запускает Linux в виртуальной машине. У контейнера нет `pmset` и нет доступа к питанию macOS. Образ можно собрать, но крышка от него не перестанет усыплять Mac. Программа должна работать на самом Mac.

## Запуск

Программа «Крышка» лежит в «Программах». Открываешь её — появляется окно. Окно можно закрыть: таймер остаётся в фоне и сам включает сон, когда время выйдет. После входа в систему он тоже на месте.

Собрать из этой папки:

```bash
./build-app.sh
```

Первый перевод переключателя спросит пароль один раз. В sudo попадает только две команды: включить и выключить `disablesleep`. Других прав root у программы нет.

Пока сон выключен, Mac не уснёт и от простоя. Отдельной настройки «только закрытая крышка» у macOS нет. Экран гаснет как обычно.

Если выйти из системы и не входить, таймер стоит: пользовательская служба не работает на экране входа. После входа она сразу возвращает сон, если время уже вышло.

## Снять

Сон к этому моменту лучше уже включить со страницы. Потом:

```bash
launchctl bootout gui/$(id -u)/com.gidon.lid-awake
rm -f ~/Library/LaunchAgents/com.gidon.lid-awake.plist
rm -rf ~/Library/Application\ Support/LidAwake
osascript -e 'do shell script "rm -f /etc/sudoers.d/lid-awake" with administrator privileges'
```

Журнал: `~/Library/Logs/lid-awake.log`
